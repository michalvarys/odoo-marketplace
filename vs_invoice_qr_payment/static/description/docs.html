Documentation — QR Payment on Invoices (SPAYD)

Installation

  1. Install the module from the Odoo Apps menu.
  2. The Python qrcode library is required. Install it with: 
    pip install qrcode[pil]
  3. No additional configuration is needed.

Setting Up Your Bank Account

  1. Go to Accounting → Configuration → Bank Accounts
  2. Add or edit your bank account
  3. Enter your IBAN in the account number field (e.g. CZ6508000000192000145399)
  4. The IBAN must pass the ISO 13616 checksum validation
  5. On your invoices, select this bank account in the Bank Account field

When Does the QR Code Appear?

The QR code is generated automatically when all of these conditions are met:

  • The invoice is posted (confirmed)
  • The invoice type is customer invoice or vendor bill
  • The invoice is not fully paid
  • A bank account with a valid IBAN is set on the invoice
  • The currency is CZK or EUR
  • The remaining amount is greater than zero

The QR code disappears automatically when the invoice is fully paid.

Where Is the QR Code Displayed?

  • Invoice form view: In the Other Info tab, below the Accounting section. Visible for both customer invoices and vendor bills.
  • PDF report: Below the payment terms section on the printed/emailed invoice.

SPAYD Format Details

The module generates QR codes using the SPAYD (Short Payment Descriptor) format.

FieldExampleDescription
SPD*1.0—Protocol identifier and version (always present)
ACCCZ6508000000192000145399IBAN of the recipient bank account
AM25000.00Payment amount (remaining balance)
CCCZKCurrency code (CZK or EUR)
X-VS202600002Variable symbol (up to 10 digits from invoice number)

Full specification: qr-platba.cz

Variable Symbol

The variable symbol (VS) is extracted from the invoice reference (ref field) or invoice number (name field). All non-digit characters are stripped, and the last 10 digits are used.

Troubleshooting

ProblemSolution
QR code not visible Check that the invoice is posted, has a valid IBAN, uses CZK or EUR currency, and is not fully paid.
Banking app shows error Verify the IBAN is a real, active bank account. Test IBANs with valid checksums but non-existent accounts may be rejected by some banking apps.
Foreign IBAN not working Some banking apps only support domestic IBANs in SPAYD. Use a local IBAN matching your customers' banking apps.
QR code too small to scan On PDF reports, the QR code is 150x150px. Print at 100% scale or zoom in on screen before scanning.
qrcode library not found Install it: pip install qrcode[pil]. The module degrades gracefully — invoices work normally without the QR code.
